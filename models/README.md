# Modele zewnętrzne (opcjonalne)

Katalog przeznaczony na lokalne modele eksperymentalne. Pliki `*.task`, `*.onnx`, `*.tflite` i `*.dat` nie są dystrybuowane ani śledzone przez Git. Sprawdź licencję i źródło każdego modelu przed pobraniem lub udostępnieniem.

`tools/mediapipe_ir_probe.py` to **wstrzymany eksperyment**, a nie zależność RGB/IR/Depth/audio. Jeśli samodzielnie uzyskasz model Face Landmarker z oficjalnego źródła, skrypt spodziewa się `models/face_landmarker.task` (lub argumentu `--model`). Nie zakładamy, że ten eksperyment działa na danej wersji MediaPipe.
